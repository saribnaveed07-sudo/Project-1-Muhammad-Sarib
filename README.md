# Hard Working But Stressed Out: UX Research for Desk-Based Professionals

## Description

This project presents UX research on desk-based professionals (ages 25-50) who work 8-10 hours a day in office, hybrid, or remote roles. Their main concern is that exercise feels like a big commitment, and missing it causes guilt. The research identifies the audience's needs and frustrations and proposes that the ideal fitness session is 10-20 minutes long.

The project includes:

1. **Target Audience:** A summary of who these users are, their core age range, daily desk time, major concern, and ideal session length.
2. **User Personas:** Three personas representing different lifestyles:
   - **Khalid Hussain**, a senior freelance graphic designer with irregular hours who struggles to keep a fitness routine alongside client work.
   - **Danielle Brooks**, a senior accountant and parent who wants to stay healthy without taking time away from family.
   - **Matilda Adams**, a call center agent working night shifts who finds that sleep and work leave no time for exercise.
3. **Empathy Maps:** A "Sees, Thinks, Feels, Does" breakdown for each persona, showing what shapes their daily experience with fitness and health.

## How to Run

This is a design project, so there is no software to install or start.

1. Clone or download the repository from GitHub.
2. Open the project folder.
3. Open `Project-1-Muhammad_Sarib.pdf` in any PDF viewer, such as Adobe Acrobat, Preview (macOS), or a web browser.

To view it from the command line on macOS, run:

```bash
open Project-1-Muhammad_Sarib.pdf
```

On Windows, run:

```bash
start Project-1-Muhammad_Sarib.pdf
```
